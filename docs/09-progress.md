## 알려진 한계·위험
- 단일 서버 메모리에 방·대기열 → 서버 재시작(배포 포함) 시 진행 중 경기 유실.
- 기록 경쟁은 시드가 브라우저에 있어 "미래 계산 봇"을 원천 차단 못 함 → 랭킹 회원 한정.
- 랜덤 매칭은 이용자가 적을 때 상대가 없을 가능성이 큼(대안 안내로 완화).
- 패들 대전은 지연 보정(예측) 없음 — 지연 큰 환경에서 조작감 저하 가능.
