## 2. 버릴 것
- Claude 판의 게임 3종 구현과 화면(GPT 판이 20종 전체를 대체)
- GPT 판의 Neon 관리형 인증(외부 의존·비밀키·이메일 보관) → Claude 판 구글 ID 토큰 방식으로 교체
- 두 판의 중복 문서(같은 주제는 하나로)
- `quickplay-codex` 저장소는 삭제하지 않고 보관(읽기 전용)

## 3. 통합 순서 (한쪽만 구현, 다른 쪽은 검토)
1. **기반**: GPT 판 코드를 `quickplay` 저장소 새 브랜치로 가져옴(이력 보존, 기존 Claude 판은 태그 `claude-v1` 로 보존)
2. **인증 교체**: Neon Auth 제거 → 구글 ID 토큰 검증 + 서명 세션 토큰. 비회원 기록 저장·로그인 시 이전 추가. GPT 판 회원 테스트(24개 경계 검사)를 새 방식으로 옮겨 유지
3. **보안 보강**: 신뢰 프록시 홉 설정(Render=1), 위조 XFF 테스트, Claude 판 검토 15건 중 GPT 판에도 해당하는 항목 재확인
4. **실측 후 판정 구조 결정**: Render(싱가포르) 배포 후 한국에서 입력→화면 반영 지연과 서버 CPU 를 측정
   - 아케이드 솔로가 체감상 느리면 → 솔로·기록 경쟁을 브라우저 실행 + 서버 재생 검증(Claude 판 뱀 방식)으로 전환. GPT 판 엔진이 순수 TS·시드 기반이라 재사용 가능
   - 문제없으면 서버 실행 유지(구조 단순)
5. **모바일 첫 화면**: 게임 목록을 첫 화면에 노출
6. **배포 전환**: 같은 Render 서비스(주소 유지)에 통합본 배포, DB 스키마는 GPT 판 마이그레이션 기준
   - ⚠️ 현재 스테이징 DB 에는 시험 기록만 있음 → 새 스키마로 바꾸며 **스테이징 시험 데이터 삭제 필요(사용자 승인 대상)**
7. **검증**: 전체 테스트 + 실제 사이트에서 20종 각 1판 이상, 두 기기 대전, 구글 로그인
