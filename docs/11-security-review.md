# 보안·공정성 검토 기록

## 2026-11-24 — 1차 독립 검토 (맥락 없는 별도 검토 에이전트, 읽기 전용)
15건 지적 → 전부 조치. 각 항목에 회귀 테스트 추가(자동화 가능한 것).

| # | 심각도 | 내용 | 조치 | 테스트 |
|---|---|---|---|---|
| 1 | 높음 | 뱀 대전 중 재접속·새로고침 시 화면의 게임이 처음부터 다시 시작되어 서버와 어긋남 | 시작 시각을 경기당 1회 고정, 재접속 시 서버가 받은 내 입력 기록(`resume`) 전달 → 이어서 플레이 | 서버 + E2E(새로고침) |
| 2 | 중간 | `trustProxy: true` 로 X-Forwarded-For 위조 시 HTTP 속도 제한 우회 | 신뢰 프록시 홉 수 설정(`TRUST_PROXY_HOPS`, Render=1), 사용자당 솔로 세션 3개 제한 | 서버 |
| 3 | 중간 | 친구전 승리가 승수 랭킹에 포함 → 승수 몰아주기 가능 | 승수 랭킹은 랜덤 대전만 집계 | 저장소 |
| 4 | 중간 | 뱀 먹이 위치가 몸 상태에 따라 달라져 "같은 조건" 위반 | 먹이당 난수 1회(몸과 무관한 후보 칸), 덮였을 때만 근처 빈칸 | 규칙 |
| 5 | 중간 | 새 탭을 열면 대기열에서 빠지고 준비가 풀림 | 새 소켓 등록 후 이전 소켓 종료 | 서버 |
| 6 | 낮~중 | 뱀 입력을 몰아 보내 결과 고르기 가능 | 보고가 5초 넘게 뒤처지면 동결 | 서버 |
| 7 | 낮음 | 끊긴 쪽 패들이 마지막 방향으로 계속 이동 | 끊기면 입력 0 | 서버 |
| 8 | 낮음 | 양쪽 다 끊기면 먼저 끊긴 쪽만 패배 | 둘 다 끊기면 기록 없이 종료 | 서버 |
| 9 | 낮음 | 새로 들어온 사람에게 이전 사람 결과가 자기 결과처럼 표시 | 입장 시 결과 초기화 | 서버 |
| 10 | 낮음 | 게임 타이머 내부 예외가 서버 전체를 종료시킬 수 있음 | 타이머 감싸기 → 해당 경기만 기록 없이 종료 | (유발 입력 없음) |
| 11 | 낮음 | 닉네임에 보이지 않는 서식 문자, 접속 시 닉네임 되돌림 | 서식 문자 제거, 접속 시 사용자 행은 "없을 때만 생성" | 서버(일부) |
| 12 | 낮음 | 솔로 저장 실패 시 재제출 불가, 긴 기록 본문 초과 | 저장 실패 시 재제출 허용, 해당 경로 2MB | — |
| 13 | 낮음 | 패들 "멈춤" 입력 유실 시 계속 이동 | 250ms 마다 현재 방향 재전송 | — |
| 14 | 낮음 | 뱀 입력마다 0틱부터 재시뮬레이션(부하 증폭) | 증분 시뮬레이션 | 규칙 |
| 15 | 낮음 | 대기 안내 시점이 시계 차이에 영향, DB 사용자 행 누락 시 결과 유실 | 대기 시간은 브라우저 시계로, 접속 전 사용자 행 보장 | — |

추가 발견(재검증 중): 속도 제한이 정적 파일까지 세어 페이지 몇 번만 열어도 차단 → `/api` 만 적용, 분당 300회로 상향.

## 남은 위험 (미조치)
- 비회원 토큰 만료·폐기 없음 → 로그인 도입 시 함께 설계.
- 기록 경쟁 시드가 브라우저에 있음 → 미래 계산 봇 차단 불가(랭킹 회원 한정으로 완화, 이상치 탐지는 후속).
- 단일 서버 메모리 상태 → 재시작 시 진행 경기 유실.
- 이용약관·개인정보 처리방침 미작성(정식 공개 전 필요).
