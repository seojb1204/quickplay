# QuickPlay PRD v1

## 1. 문제와 사용자
- **누가**: 다른 게임(롤·발로란트 등) 매칭을 기다리는 사람, 쉬는 시간에 짧게 놀고 싶은 사람.
- **문제**: 짧은 대기 시간에 설치·가입 없이 바로 누군가와 붙을 수 있는 가벼운 게임이 없다.
- **해결**: 웹 주소 하나로 즉시 접속 → 게임 고르기 → 혼자/친구/랜덤 1:1.

## 2. 핵심 흐름 (확정)
- 흐름 A 게임 우선: 홈 → 게임 → 솔로/친구/랜덤 → 플레이 → 결과 → 재대결 또는 다른 게임
- 흐름 B 친구방 우선: 홈 → 방 만들기 → 초대 → 게임 고르기 → 플레이 → 결과 → 같은 친구와 다른 게임
- 확장 예정: "아무 게임 랜덤" 진입(대기열이 게임별이라 1단계 범위 밖)

## 3. 가치 검증 방법 (제안)
| 가설 | 지표 | 1차 목표(가안) |
|---|---|---|
| 설치 없이 바로 시작한다 | 첫 접속 → 첫 플레이 시작까지 시간 | 중앙값 20초 이내 |
| 친구와 하고 싶다 | 생성된 친구방 중 2명 입장 비율 | 50% 이상 |
| 랜덤 상대가 있다 | 랜덤 대기 중 매칭 성사율(60초 내) | 측정 후 결정 — 초기 이용자 적을 때 가장 큰 위험 |
| 다시 온다 | 7일 내 재방문율 | 20% 이상 |

※ 지표 수집 도구는 아직 없음(개인정보 최소 수집 원칙 → 쿠키 없는 집계 방식 검토, 02-policies.md 미결).

## 4. 범위
- **최종 목표**: 고전 미니게임 20종 × 3모드, 비회원 즉시 플레이, 선택 로그인, 승패·랭킹·통계.
- **현재 구현(1~3단계 일부)**: 공통 플랫폼 + 대표 3종(패들 랠리·오목·꼬리잡기 뱀). 진행 현황은 09-progress.md.
- **제외(초기)**: 티어·시즌, 광고, 결제, 외부 개발자 게임 등록 SDK.

## 5. 비기능 요구
- PC·모바일 웹 동시 지원(터치 버튼 최소 44~48px).
- 준비된 두 사람의 랜덤 매칭 완료 p95 3초 이내.
- 경쟁 결과는 서버가 판정·검증(클라이언트 주장 불신).
- 서버 비용: 초기 무료 구간 우선, 유료 전환은 승인 후.
