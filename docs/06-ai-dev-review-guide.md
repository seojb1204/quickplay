# AI 개발·검토 지침

## 역할 (현재 실제 상태)
- 원래 계획: Codex = 주 개발, Claude Code = 독립 검토.
- 현재: Codex 미연결 → **Claude 가 주 개발**. 독립 검토는 작업 맥락이 없는 별도 검토 에이전트로 수행(완전한 독립은 아님).
- Codex 를 연결하면: Codex 가 구현·PR, Claude 는 PR 검토 역할로 전환(아래 체크리스트 그대로 사용).

## 작업 규칙
1. 작업 전 `docs/09-progress.md` 와 관련 규칙서 확인.
2. 브랜치 → PR → CI 통과 → 검토 → 병합. main 직접 push 금지(저장소 설정에서 보호 규칙 필요).
3. 공통 파일(`hub.ts`, `protocol.ts`, `registry.ts`)은 한 번에 한 작업만 수정. 게임별 작업은 자기 폴더만.
4. 테스트 삭제·기준 완화로 통과시키기 금지. 같은 문제 자동 수정은 2회까지, 이후 로그·가설과 함께 보고.
5. 비밀키는 환경변수로만. 코드·로그·PR 본문에 쓰지 않는다.
