# 확정 정책 / 미결 사항

## 확정 (기획서 기준)
- 20개 게임, 모든 게임 솔로·친구·랜덤 1:1
- 비회원 즉시 플레이, 로그인은 선택
- 친구·솔로 중도 자유 종료 / 랜덤 중도 이탈은 기권패
- 랜덤 매칭에 봇을 사람인 척 넣지 않음 → 대기 15초 후 "혼자 하기·친구 초대" 대안 안내
- 티어·시즌 없음, 초기 광고·결제 없음

## 구현하며 정한 운영 규칙 (변경 가능, 이견 있으면 알려주세요)
| 항목 | 정한 값 | 이유 |
|---|---|---|
| 랜덤 연결 끊김 유예 | 15초 후 기권패 | 모바일 잠깐 끊김 구제 vs 상대 대기 시간 |
| 친구전 기권 | 기록 없이 종료(`abandoned`) | "친구전 자유 종료" 정책 |
| 재대결 | 자리·선공 교대 | 오목 흑 유리 등 선공 이점 상쇄 |
| 랭킹 | **회원 기록만** 집계 | 게스트 대량 생성으로 승수 조작 방지 |
| 게스트 기록 | 브라우저에 저장된 토큰에 연결(지우면 사라짐) | 개인정보 수집 없음 |
| 컴퓨터 상대 솔로 결과 | 서버 저장 안 함 | 서버 검증 불가 |
| 뱀 솔로 기록 | 서버 재생 검증 후 저장 | 위조 방지 |
| 닉네임 | 2~12자, 무작위 기본값 | 최소 입력 |
