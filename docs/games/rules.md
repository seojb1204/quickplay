# 20개 게임 규칙 명세 v1

> 상태 표기: **확정** = 코드·테스트로 구현됨 / **초안** = 구현 전 설계안(구현 시 재검토)
> 모든 게임은 기존 상표명·그래픽·사운드를 쓰지 않는 자체 구현물이다. 화면 명칭은 `packages/shared/src/catalog.ts` 기준.

## 공통 규칙

| 항목 | 규칙 |
|---|---|
| 모드 | 모든 게임 솔로 / 친구 1:1 / 랜덤 1:1 |
| 솔로 | 상대가 필요한 게임은 AI(쉬움·보통·어려움), 혼자 하는 게임은 기록 도전 |
| 친구전 중도 종료 | 자유. 결과 `abandoned`, 승패 기록 없음 |
| 랜덤전 중도 종료 | 나가기·기권 = 기권패. 연결 끊김은 15초 유예 후 기권패(`disconnect`) |
| 재대결 | 같은 방에서 둘 다 준비 → 자리(선공) 교대 후 시작 |
| 카운트다운 | 매치 시작 3초 후 실제 시작(서버 시각 기준) |
| 판정 위치 | 실시간·턴제: 서버가 판정 / 기록 경쟁: 서버가 입력 기록을 재생해 점수 계산 |
| 기록 경쟁 공정성 | 양쪽 같은 시드(난수 기준값) → 같은 맵·같은 블록 순서. 뱀 먹이는 같은 후보 칸 순서(후보 칸이 자기 몸에 덮였을 때만 가까운 빈칸으로 밀림) |
| 알려진 한계 | 시드가 클라이언트에 있으므로 "미래를 미리 계산하는 봇"은 원천 차단 불가 → 랭킹은 회원만, 이상 기록 탐지는 후속 과제 |

## 1. 패들 랠리 (Pong 계열) — **확정**
- 방식: 실시간 직접 대전. 서버 60Hz 시뮬레이션, 30Hz 상태 방송. 클라이언트는 방향(-1/0/1)만 전송.
- 필드 800×500, 패들 높이 90, 속도 420/s. 공 시작 360/s, 패들에 맞을 때마다 ×1.06(최대 900). 맞은 위치에 따라 반사각 최대 약 ±56°.
- 승리: 먼저 5점. 시간 제한 180초 → 점수 높은 쪽 승, 같으면 **무승부**.
- 서브: 득점 후 1초 대기, 점수 합이 짝수면 왼쪽(seat0) 방향. 서브 각도는 시드 난수 ±30°.
- 솔로 AI: 공 y 추적. 쉬움(자기 진영 절반에서만 반응, 데드존 40) / 보통(22) / 어려움(10).
- 테스트: 결정성, 벽·패들 경계, 고속 공 관통 방지, 5점 승리, 시간 종료 무승부.

## 2. 꼬리잡기 뱀 (Snake) — **확정**
- 방식: 기록 경쟁. 20×20, 초당 8틱. 벽·몸 충돌 시 종료. 먹이 1개 = 1점.
- 대전: 같은 시드로 90초(720틱). 점수 높은 쪽 승 → 동점이면 마지막 득점 틱이 빠른 쪽 승 → 0:0 또는 완전 동일이면 무승부.
- 위조 방지: 1초마다 입력 기록 전송. 과거 틱 재작성 금지, 실제 경과 시간+2초를 넘는 진행 금지, 보고가 5초 넘게 뒤처지면 그 시점에서 동결(이후 입력 무시), 제한 시간 후 3초 내 미제출분은 마지막 방향으로 끝까지 재생해 확정.
- 재접속·새로고침: 서버가 받은 내 입력 기록을 돌려줘 그 지점부터 이어서 플레이.
- 솔로: 서버 발급 시드, 종료 시 입력 기록 제출 → 서버 재생 점수만 저장. 경과 시간보다 긴 플레이 주장·중복 제출·타인 세션 거부. 최대 1시간.

## 3. 벽돌 부수기 (Breakout 계열) — 초안
- 기록 경쟁, 같은 시드(벽돌 배치·공 초기각). 목숨 3개, 제한 120초.
- 점수: 벽돌 1개 10점, 단 클리어 시 남은 초×5 보너스. 동점 → 클리어 시간 빠른 쪽.
- 검증: 패들 입력(틱별 x 위치 변화) 기록 재생. 물리는 패들 랠리 엔진 방식(고정 틱) 재사용.

## 4. 블록 낙하 (낙하 블록 퍼즐) — 초안
- 기록 경쟁, 같은 시드로 같은 블록 순서(7종 묶음 무작위). 제한 120초.
- 점수: 1/2/3/4줄 동시 제거 100/300/500/800 × 레벨. 꼭대기 도달 시 종료.
- 대전 공격(줄 보내기)은 **넣지 않음** — 기록 경쟁 방식 유지(재미 부족 시 2단계 검토).
- 명칭·블록 색·사운드는 유명 상표 제품과 구분되게 자체 제작.

## 5. 우주 방어전 (고정 슈팅) — 초안
- 기록 경쟁, 같은 시드 적 편대 패턴. 목숨 3, 제한 120초. 점수: 적 종류별 10/20/30, 편대 전멸 시 다음 웨이브.
- 동점 → 피격 횟수 적은 쪽 → 무승부.

## 6. 소행성 지대 — 초안
- 기록 경쟁, 같은 시드 소행성 생성. 관성 이동·회전·발사. 목숨 3, 제한 120초.
- 점수: 큰 20 / 중간 50 / 작은 100. 동점 → 생존 시간 긴 쪽.

## 7. 길 건너기 (Frogger 계열) — 초안
- 기록 경쟁, 같은 시드 차선 패턴. 제한 90초. 목표 지점 1회 도착 = 100점 + 남은 시간 보너스, 반복 가능.
- 동점 → 마지막 도착 시각 빠른 쪽.

## 8. 폭탄 미로 — 초안 (실시간, 고난도)
- 실시간 직접 대전. 13×11 격자, 서버 20Hz 틱(격자 이동이라 60Hz 불필요). 폭탄 2초 후 십자 폭발, 파괴 가능한 벽에서 아이템(사거리·개수) 시드 결정.
- 승리: 상대가 폭발에 맞으면 승. 동시 사망 = 무승부. 제한 120초 후 남은 공간 축소(서든데스), 180초에 무승부.
- 솔로: AI(위험 칸 회피 + 벽 파괴 + 상대 근처 설치). 공정성 위험: 접속 지연 차이 → 입력 지연 보정(서버 수신 시각 기준) 필요.

## 9. 탱크 결투 — 초안 (실시간)
- 실시간 직접 대전. 고정 맵(시드로 3종 중 선택), 서버 30Hz. 체력 3, 포탄 쿨다운 0.6초, 벽 반사 1회.
- 승리: 상대 체력 0. 제한 120초 → 남은 체력 많은 쪽, 같으면 무승부.

## 10. 두더지 탭 — 초안
- 기록 경쟁, 같은 시드 출현 순서·시각. 60초. 맞히면 +10, 폭탄 두더지 누르면 -20.
- 검증: 탭 입력(틱, 칸) 기록을 서버가 출현표와 대조. 반응 시간 100ms 미만 연속은 이상치로 표시(랭킹 제외).

## 11. 오목 — **확정**
- 턴제. 15×15, 흑(seat0) 선공, **자유룰**(5목 이상 승리, 금수 없음). 판이 가득 차면 무승부.
- 한 수 30초. 초과 시 시간패(`timeout`). 재대결마다 흑백 교대.
- 공정성 메모: 자유룰은 흑이 유리 → 흑백 교대로 상쇄. 렌주룰(흑 3-3·4-4·장목 금지)은 미결(02-policies.md).
- AI: 칸별 공격·수비 패턴 점수. 어려움 = 최고점, 보통 = 상위 3개 중 무작위(4목 위협은 반드시 대응), 쉬움 = 상위 6개 중 무작위(열린4 이상 위협 70% 대응).

## 12. 삼목 (틱택토) — 초안
- 턴제 3×3, 한 수 15초. 무승부가 잦으므로 **3판 2선승**(선공 교대)을 한 경기로 본다.
- AI: 쉬움 무작위 / 보통 1수 앞 / 어려움 미니맥스(지지 않음).

## 13. 사목 떨구기 (Connect Four 계열) — 초안
- 턴제 7열×6행, 한 수 20초. 4개 연결 승리, 판 가득 = 무승부. 선공 유리 → 재대결 교대.
- AI: 깊이 제한 미니맥스(쉬움 2 / 보통 4 / 어려움 7).

## 14. 리버시 — 초안
- 턴제 8×8, 한 수 30초. 둘 곳 없으면 자동 패스, 양쪽 모두 없으면 종료. 돌 많은 쪽 승, 같으면 무승부.
- AI: 위치 가중치 + 깊이 제한 탐색.

## 15. 체커 — 초안
- 턴제 8×8(영미식). 잡을 수 있으면 반드시 잡기(연속 잡기 포함), 끝줄 도달 시 왕. 한 수 30초.
- 종료: 상대 말 전멸 또는 이동 불가 = 승. 40수 동안 잡기·승급 없으면 무승부.

## 16. 함대 포격전 (Battleship 계열) — 초안
- 턴제 10×10, 함선 5·4·3·3·2. 배치 60초(시간 초과 시 자동 배치). 한 발 20초.
- **숨겨진 정보는 서버만 보관** — 상대 배치는 명중/빗나감 결과만 전송.
- 승리: 상대 함선 전부 격침. 명중 시 연속 사격 **없음**(번갈아 1발, 선공 교대로 공정성 확보).

## 17. 지뢰 탐색 — 초안
- 기록 경쟁, 같은 시드 지뢰 배치(첫 클릭 안전 보장 규칙도 시드로 결정). 16×16, 40개, 제한 180초.
- 승리: 먼저 전부 연 쪽 → 둘 다 실패면 연 칸 수 많은 쪽 → 무승부.

## 18. 숫자 합치기 (2048 계열) — 초안
- 기록 경쟁, 같은 시드 타일 생성. 제한 180초 또는 움직일 수 없을 때 종료. 점수 = 합쳐진 타일 값 합.
- 원작이 MIT 라이선스이나 코드·디자인은 자체 구현, 명칭은 "숫자 합치기".

## 19. 카드 짝맞추기 — 초안
- 기록 경쟁, 같은 시드 카드 배치(4×4 → 8쌍). 제한 90초. 승부: 모두 찾은 시간 → 시도 횟수 적은 쪽.
- 검증: 카드 정보는 서버만 보관하고 뒤집을 때마다 공개(클라이언트에 전체 배치를 보내면 부정행위 가능) → 이 게임은 **서버 상호작용형** 기록 경쟁.

## 20. 단어 맞히기 (Hangman 계열) — 초안
- 기록 경쟁, 같은 시드로 같은 단어 목록(한국어 초성/영단어 중 결정 필요 — 미결). 오답 6회, 제한 120초 동안 연속 출제.
- 점수: 맞힌 단어 수 → 동점이면 총 오답 적은 쪽. 정답 단어는 서버만 보관(위조 방지).
- 단어 목록 라이선스 확인 필요.
